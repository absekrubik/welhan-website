# Welhan Abroad Study – website

Static HTML/CSS/JS rebuild of welhanabroadstudy.com. Hosted on GitHub Pages.

- Pages: `*.html` in the repo root, assets in `assets/`.
- Forms open the visitor's email app (no server on GitHub Pages).
- The OSHC comparison prices are in `assets/js/oshc-data.js`.
- The full PHP version (admin dashboard, saved forms, blog, price editor, email notifications) lives on the `php-version` branch and needs PHP hosting.
